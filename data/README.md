## MNIST provenance

Acquisition is documented in `scripts/fetch_mnist.sh`: the pjreddie MNIST CSV mirror, with the halimb/MNIST-csv GitHub mirror as fallback. MNIST (LeCun, Cortes and Burges) is cited in the report. The combined CSV was checked against train + test byte-for-byte. Clustering the combined data does not imply held-out classification accuracy; purity is a clustering diagnostic.

Run `bash scripts/fetch_mnist.sh` to download and verify MNIST. Generate the synthetic workload using the README recipe; verify it with `python3 scripts/verify_data.py --files blobs_big.csv`. C++ random-distribution implementations can vary, so a generated file with a different hash is a new workload instance. Expected dataset hashes are in data/checksums.json, while SUBMISSION_MANIFEST.json covers only packaged files.

## Public source equality check — 12 November 2026

Fresh downloads from https://data.pjreddie.com/files/mnist_train.csv and https://data.pjreddie.com/files/mnist_test.csv were byte-identical to the local project inputs. The combined file was verified as their exact concatenation. The source page is https://pjreddie.com/projects/mnist-in-csv/. The GitHub mirror is a fallback accepted only if its content matches the same recorded hashes.

The synthetic CSV has no public download URL: it was generated by scripts/gen_blobs.cpp. The two retained HPC copies have identical checksums, but are intentionally omitted to reduce the Canvas upload size. Local retained data have not been deleted.
